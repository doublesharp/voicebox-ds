## Download

Choose a prebuilt package from the [latest Voicebox DS release](https://github.com/doublesharp/voicebox-ds/releases/latest).

- [**macOS (Apple Silicon)**](https://github.com/doublesharp/voicebox-ds/releases/latest/download/Voicebox-DS-macOS-arm64.zip). Unzip the download and move `Voicebox DS.app` to Applications.
- [**Linux (x64)**](https://github.com/doublesharp/voicebox-ds/releases/latest/download/Voicebox-DS-Linux-x64.deb). On Debian-based distributions, run `sudo apt install ./Voicebox-DS-Linux-x64.deb` from the download folder. You can also [build from source](/developer/setup) or [use Docker](/overview/docker).
- [**Windows (x64)**](https://github.com/doublesharp/voicebox-ds/releases/latest/download/Voicebox-DS-Windows-x64-setup.exe). Open the setup executable and follow the installer. For NVIDIA GPUs, see the [optional CUDA setup](https://github.com/doublesharp/voicebox-ds/blob/doublesharp/docs/DOUBLESHARP_BUILDS.md#windows-and-cuda).

## First Launch

Open **Generate** and select **Try a voice**. Voicebox DS downloads Kokoro on first use and saves the sample in **Recent takes**.

Voicebox DS keeps its own library and model cache. Use **Import Voice** or **Import project** to bring in previously exported work.

## System Requirements

### Minimum

- **OS:** macOS 11+, Windows 10+, or Linux
- **RAM:** 8GB
- **Storage:** 5GB free space (for models and data)
- **CPU:** Modern multi-core processor

### Recommended

- **RAM:** 16GB+
- **GPU:** CUDA-capable NVIDIA GPU (for faster generation)
- **Storage:** 10GB+ free space

<Callout type="info">
  CPU inference is supported but significantly slower than GPU. A CUDA-capable GPU is highly recommended for real-time workflows.
</Callout>
